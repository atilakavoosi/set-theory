## 📖 Background

Set theory kept tripping me up — elements, subsets, nested sets, all the notation. Instead of reading another textbook, I sat down with [Claude AI](https://claude.ai) and asked it to rebuild my intuition from scratch using real-world analogies, step-by-step algorithms, and interactive experiments. This page is the result.

---

## ✨ Features

- **12 complete chapters** — mental models, symbols, nested sets, power sets, and more
- **Interactive lab** — type any set expression, instantly check membership (∈) and subset (⊆)
- **Power set explorer** — generates all subsets automatically with visual output
- **15-question smart quiz** — immediate feedback that diagnoses *where* your thinking went wrong
- **Cheat sheet & decision tree** — the 10 most common mistakes, recognition tricks, and a universal algorithm
- Zero dependencies · Single HTML file · Works offline
